# Project Screenshots

Store the important screenshots/photos of your project in this folder.

## Recommended screenshots

- Home / landing screen
- Main dashboard
- Important feature or workflow
- Final output / result
- Login or user flow, if relevant
- Hardware setup and prototype photos for hardware projects

## Naming convention

Use clear names such as:

- `01-home.png`
- `02-dashboard.png`
- `03-feature.png`
- `04-result.png`
- `05-hardware-setup.jpg`

Do not upload screenshots containing passwords, API keys, tokens, personal credentials, or other sensitive information.

## Adding screenshots to README

You can display important screenshots in the main `README.md` using a relative path, for example:

```md
![Project Dashboard](assets/screenshots/02-dashboard.png)
```
